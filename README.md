# Timbangan Rupa: Lab Keseimbangan Desain

Lab Maya Seni Rupa untuk SD kelas 3-4. Bersama Mira si merak, murid menata potongan kertas di Galeri Kelas sambil membaca **Timbangan Rupa** yang miring ke sisi yang terasa lebih berat. Murid menemukan bahwa ukuran, warna, jumlah, dan letak memengaruhi berat visual, lalu membuat karya **simetris** (setangkup), **asimetris** (tidak kembar tetapi seimbang), dan **radial** (memancar dari tengah).

**Mainkan:** https://tretanjamal.github.io/timbangan-rupa/

## Isi
1. Cari Sumbu: garis cermin dan Kuas Cermin
2. Percobaan Berat Visual: ukuran, warna, jumlah, jarak
3. Seimbang Tanpa Kembar: teka-teki asimetris
4. Pusat Memancar: mengenali dan membuat pola radial
5. Pameran Kelas: memilih jenis keseimbangan, menyusun, dan menanggapi karya

Layar **Hasil Belajarku** menampilkan keterampilan murid, galeri karya, Catatan untuk Guru, dan sertifikat cetak. Tidak ada data pribadi yang dikumpulkan; progres hanya tersimpan di perangkat.

## Teknis
HTML5 + JavaScript murni, berjalan penuh tanpa internet (juga dari `file://`). Kanvas 1280x720, mouse, sentuh, dan papan ketik.
